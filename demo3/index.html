Assembly Procedure

A guided VR procedure that turns a multi-step mechanical assembly into a tactile, ordered learning experience.

View project on GitHub ↗Back to all work

About the project

Players install and wind a spring, position a cover, tighten three screws, seat a pressure plate, and stamp the finished assembly. Each stage must be completed in order.

Socketed parts, two-handed handling, constrained winding motions, and clear success or failure feedback make the procedure physical while keeping progress easy to understand.
