Wi-Fi Heatmap

See wireless coverage in your real room: a tracked ESP32 probe measures signal strength while Quest paints a cloud of coloured voxels in passthrough.

About the project

A small ESP32 probe clips to either controller and sends timestamped readings over Bluetooth. A calibrated antenna offset matches each measurement to the controller’s tracked position. An M5StickC Plus2 also supports controller or wrist mounting.

Measure one access point or a network’s access points on a shared channel. Depth occlusion places the coverage cloud behind real objects, while a movable room miniature helps inspect the survey. Record sessions and replay them using room anchors.

Try it

This prototype requires an ESP32 probe and a personal or unmanaged Quest 3. School-managed headsets block the room and anchor access it needs. The README includes hardware, firmware, installation, and verified limitations.
