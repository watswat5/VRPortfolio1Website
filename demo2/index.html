Table Tennis Trainer

A standalone VR training experience built around responsive paddle control, believable ball movement, and two ways to practice.

View project on GitHub ↗Back to all work

About the project

The trainer maps the player’s controller movement directly to a virtual paddle. Ball flight combines gravity, drag, bounce response, and spin to make each return feel different.

Normal Practice focuses on consistent returns and target accuracy. AI Opponent mode adds a computer-controlled paddle and rally scoring for a more competitive session.
